Confidential Agent Commerce

Two AI agents buy and sell from each other — and the price is encrypted on the public chain. Everyone can see that a payment happened. Only the seller, the buyer, and a registered auditor can see how much. Every run below is a real transaction on Stellar testnet, about 20 seconds.

  1. 1 Pip shopscompares two merchants' quotes
  2. 2 They agree a priceneither side sees the other's number
  3. 3 Pip proves itzero-knowledge proof, in your browser
  4. 4 It settleson-chain — with no amount visible
  5. 5 Momo decrypts & deliversand Pip re-checks against the chain

Demo keys are published on purpose (testnet, worthless): anyone can decrypt this demo's own amounts. The protocol hides amounts from anyone without keys.

Run payment makes one deal now. Run every 60 s lets Pip keep trading on its own, one round per minute, until you press Stop; while it runs, anything you change in Configure the agents applies at the next round, and Pip says what changed.

Merchant identities (keys, on-chain registration) and terms are fixed. Pricing is yours to set: the negotiation, the till, and the market board all run with what you configure here, and while Pip is running on its own, every change applies at its next round. Terms are not knobs on purpose: a verdict at the till has to be re-derivable from the chain alone, or the refund worker could refund delivered goods or strand funds. Saved in this browser.
Press Run payment for one deal, or Run every 60 s and Pip keeps dealing on its own. This is not a simulation: each round is a new payment negotiated (or challenged over MPP), proven, and settled on testnet while you watch. About 20 seconds each.     Bring your own agent

    Any environment can join. Your agent gets a persistent identity, its own face, and pays the seller here confidentially. When it does, the seller's decrypted total on this page includes your payment.
    git clone https://github.com/Stellar-Light/confidential-agent-commerce
cd confidential-agent-commerce/agents
npm install
node join.mjs --name YourAgent --amount 2        # negotiate, pay, get signed goods
node mpp-buy.mjs --merchant kiki                 # buy over MPP: 402, pay, credential, receipt
for i in 1 2 3; do node join.mjs; sleep 120; done   # your agent on its own clock
